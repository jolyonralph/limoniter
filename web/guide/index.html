User guide

This guide shows you how to get things done in Limoniter, step by step. Start with Getting started if you're new; after that, each page stands on its own, so jump to whatever you need.

For a list of everything Limoniter can do, see the full feature list. Inside Limoniter, Help › How things work has short notes on many of the same things, and F1 finds any command by describing what it does.

On a Mac, press Cmd wherever this guide says Ctrl.

Pages

  1. Getting started

    Install Limoniter on Windows, macOS or Linux, open your first files, find your way around the window, and find any command with F1.

  2. Editing text and hex

    Edit text and bytes in Limoniter: selecting, column editing, the undo tree, finding and replacing, laying out text, table view and hex mode.

  3. Character sets and old machines' text

    Open and edit text from older computers byte for byte: choosing a character set, line endings, the kinds-of-computer presets, the character table, previews and machine themes.

  4. The disk and tape browser

    Open disk images, tapes and archives from older computers as folders, take files out of them, put files on them, and make new blank images.

  5. BASIC listings

    List BASIC programs from Commodore, Spectrum, BBC, Atari, MSX, Apple II, TRS-80 and other machines, edit them as text, and turn them back into programs to save, run or send.

  6. Assembling and running

    Run programs with F9 on the built-in ZX Spectrum, an emulator or a real machine; assemble Z80, 6502, 6809 and 68000 source; and send files to the machines they're for.

  7. Debugging

    Debug Z80, 6502, 6809 and 68000 programs and Spectrum BASIC with breakpoints, stepping, registers, watches, memory and the profiler, on the built-in Spectrum or in an emulator.

  8. Git

    Keep your work's history with Git in Limoniter: the Git wizard for beginners, committing, pushing and pulling, branches, conflicts, history and blame.

  9. Remote files

    Open, edit and save files on a server over SFTP, open a file from a web address, and send files to FTP and SFTP servers on your machines.

  10. Settings

    Change how Limoniter looks and behaves: the Settings window, themes for the window and for documents, autosave and backups, new files, hex mode, and file types on Windows.
